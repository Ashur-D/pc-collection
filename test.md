## 1. Core System & Hardware

### System Optimization & Debloat
* [WinUtil](https://github.com/ChrisTitusTech/winutil) — Modular toolbox for updates, debloat routines, and automated package management.
* [Sophia Script](https://github.com/farag2/Sophia-Script-for-Windows) — Granular PowerShell automation script for deep OS configuration.
* [Process Lasso](https://bitsum.com/) — Automated CPU affinity and process priority rules to eliminate thread lockups.
* [FanControl](https://github.com/Rem0o/FanControl.Releases) — Lightweight, hardware-agnostic fan curve manager for both motherboard and GPU headers.
* [MSI Afterburner](https://www.msi.com/Landing/afterburner/graphics-cards) — GPU overclocking, voltage curve management, and RTSS hardware overlays.
* [PowerToys](https://github.com/microsoft/PowerToys) — Microsoft productivity suite including FancyZones and system remappers.

### Hardware Telemetry & Sensor Diagnostics
* [HWiNFO64](https://www.hwinfo.com/) — Comprehensive sensor polling, power draw readouts, and thermal limit monitoring.
* [GPU-Z](https://www.techpowerup.com/gpuz/) & [CPU-Z](https://www.cpuid.com/softwares/cpu-z.html) — Zero-install silicon specifications and clock-speed verification.
* [CrystalDiskInfo](https://crystalmark.info/en/software/crystaldiskinfo/) — S.M.A.R.T. health, read/write cycles, and NVMe temperature telemetry.
* [Twinkle Tray](https://github.com/xanderfrangos/twinkle-tray) — Native DDC/CI external monitor brightness controls via the taskbar.

### Driver & Runtime Deployment
* [NVCleanstall](https://www.techpowerup.com/download/techpowerup-nvcleanstall/) — Custom Nvidia driver builder without telemetry or bundled bloat.
* [DDU (Display Driver Uninstaller)](https://www.wagnardsoft.com/display-driver-uninstaller-DDU-) — Clean-slate removal of display and audio drivers in Safe Mode.
* [Vcredist AIO](https://github.com/abbodi1406/vcredist) — Silent installer bundle covering all modern Visual C++ runtimes.
* [Ventoy](https://www.ventoy.net/en/index.html) & [Rufus](https://rufus.ie/en/) — Bootable USB builders with support for multi-ISO boot and Windows requirement bypasses.

### Disk Space & Storage Cleaners
* [WizTree](https://diskanalyzer.com/) — Instant MFT-based disk space visualizer.
* [Geek Uninstaller](https://geekuninstaller.com/) — Fast portable uninstaller with residual file and registry cleanup.
* [BleachBit](https://www.bleachbit.org/) — Targeted cleaner for system caches, junk files, and temporary logs.

### Agentic Development Environments (ADEs)

* [Pane](https://runpane.com/) — Dynamic visual canvas tailored for multi-agent front-end iteration.

## 3. Productivity & Media Utilities

### Instant Search & App Launchers
* [Everything (Voidtools)](https://www.voidtools.com/) — Instantaneous filename search using the NTFS Master File Table.
* [Flow Launcher](https://github.com/Flow-Launcher/Flow.Launcher) — Customizable keyboard app launcher with extensible plugin support.
* [Kando](https://github.com/kando-menu/kando) — Cross-platform radial pie menu for quick shortcut access.

### Hardened Browsers & Web Utilities
* [Zen Browser](https://zen-browser.app/) — Firefox fork focusing on vertical tabs, tab workspaces, and user privacy.
* [Helium](https://github.com/imputnet/helium-chromium) — Stripped-down, privacy-hardened Chromium build.
* [PrivateBin](https://github.com/PrivateBin/PrivateBin) / [MicroBin](https://github.com/szabodanika/microbin) — Zero-knowledge client-side encrypted paste services.

### Audio & Video Production
* [DaVinci Resolve](https://www.blackmagicdesign.com/ca/products/davinciresolve) — Industry-grade non-linear editor, color grader, and audio suite.
* [OBS Studio](https://obsproject.com/) — Open-source video recording and live streaming studio.
* [LosslessCut](https://github.com/mifi/lossless-cut) — Zero-reencode cutting and trimming utility powered by FFmpeg.
* [HandBrake](https://github.com/HandBrake/HandBrake) — Multi-format batch video transcoder.

### PDF & Document Processing
* [Stirling-PDF](https://github.com/Stirling-Tools/Stirling-PDF) — Self-hosted local web utility to merge, split, OCR, and edit PDFs.
* [PDF-XChange Editor](https://www.pdf-xchange.com/product/pdf-xchange-editor) — Fast desktop PDF reader with advanced markup and annotation tools.
* [QuickLook](https://github.com/QL-Win/QuickLook) — macOS-style Spacebar preview for documents, images, and archives.

### LLM Data & Markdown Extractors
* [Docling](https://github.com/docling-project/docling) — Advanced layout analysis parser converting complex PDFs and tables into Markdown.
* [MarkItDown](https://github.com/microsoft/markitdown) — Microsoft tool for converting Office documents, PDFs, and audio metadata to Markdown.
* [MinerU](https://github.com/opendatalab/MinerU) — Academic paper extractor specialized in dense formulas and mathematical typesetting.

## 4. Desktop Customization & Rice

### Shell & Context Menu Modification
* [StartAllBack](https://www.startallback.com/) — Classic taskbar, Start menu, and Explorer ribbon restoration for Windows 11.
* [Windhawk](https://github.com/ramensoftware/windhawk) — Safe process modification and system mod manager without binary patching.
* [Nilesoft Shell](https://github.com/moudey/Shell) — Deeply customizable, lightweight replacement for the Windows 11 cascading context menu.
* [WinSetView](https://github.com/LesFerch/WinSetView) — Globally standardizes folder view preferences across File Explorer.

### Tiling Window Managers & Status Bars
* [GlazeWM](https://github.com/glzr-io/glazewm) — Tiling window manager inspired by i3/sway for Windows.
* [Komorebi](https://github.com/LGUG2Z/komorebi) — Highly configurable, multi-monitor tiling window manager written in Rust.
* [YASB](https://github.com/amnweb/yasb) — Modern, customizable top bar for Windows setups.
* [Starship](https://github.com/starship/starship) & [Fastfetch](https://github.com/fastfetch-cli/fastfetch) — Cross-shell customizable prompt and terminal system fetch tool.

### Color Schemes & Palettes
* [Catppuccin](https://github.com/catppuccin) — Pastel-focused theme palette across four flavors (Latte, Frappé, Macchiato, Mocha).
* [Rosé Pine](https://github.com/rose-pine) — Minimal, muted color scheme for code editors and terminals.
* [Nord](https://github.com/nordtheme) — Arctic, bluish-gray clean palette.
* [Tokyo Night](https://github.com/tokyo-night) — Crisp dark theme celebrating downtown Tokyo neon aesthetics.

### Wallpapers & Visual Assets
* [Steam Workshop Favorites](https://steamcommunity.com/profiles/76561198824218763/myworkshopfiles/?appid=431960&sort=score&browsefilter=myfavorites&view=imagewall) — Curated Wallpaper Engine animated collection.
* [Personal Wallpaper Archive](https://github.com/Ashur-D/wallpapers) — Raw high-resolution wallpapers.
* [WallSync](https://github.com/leroiduflow/WallSync) — Curated index of public wallpaper scrapers and sources.
